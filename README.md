# AI Game Security Lab — research disclosure

This package is a documentation/evidence disclosure for the frozen
`cs2_multitarget_ft_v1` perception model. It is **not** a software, model-weight,
or dataset release.

## Contents

- MIT license and third-party notices.
- Model card and manifest.
- Dataset card, training record, evaluation record, and deviations.
- Replay review and risk/legal documentation.

## Intended use

Academic study of perception evaluation and anti-cheat/defense analysis in
controlled offline environments. Do not use for live multiplayer cheating,
anti-cheat bypass, unauthorized input, surveillance, or any illegal activity.
Academic status is not a legal immunity.
