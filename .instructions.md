## 🔴 CRITICAL: Control Layer Constraints

### apply_mouse Parameter
- **MUST NOT** be hardcoded to `False` in `realtime_loop.py` or `orchestrator.py`
- **MUST** be controlled via CLI `--apply-mouse` flag (default: dry-run mode)
- **MUST** use `RealtimeLoopConfig(apply_mouse=...)` for configuration

### CSV Logging
- **MUST** be unconditionally enabled for all control paths
- **MUST** call `backend.send_relative_move()` with CSVLoggerBackend or ChainedBackend
- **MUST** call `flush()` after every movement record
- **MUST** output to `runs/predict/control_moves_YYYYMMDD_HHMMSS.csv`

### Backend Architecture
- **MUST** preserve `ChainedBackend` class in `cv_agent/control/backends/chained.py`
- **MUST** support `always_include_csv=True` in factory function
- **MUST** allow `custom_handler` injection for Win32 backend
- **MUST** keep `run_real.py` Hook mechanism intact

### Safety Mechanisms
- **MUST** preserve ESC and F12 global hotkeys for emergency stop
- **MUST** implement `_mouse_paused()` and `_loop_stopped()` checks
- **MUST** use try...finally for resource cleanup

## 📋 Quick Checklist

When modifying `cv_agent/control/` or `vision/stream/`:

- [ ] No hardcoded `apply_mouse=False`
- [ ] ChainedBackend exists and is functional
- [ ] CSV logging is unconditional
- [ ] `flush()` is called after each write
- [ ] Kill switch (ESC/F12) is preserved
- [ ] try...finally blocks are present
